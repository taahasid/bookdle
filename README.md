# Bookdle

A daily book-guessing game. Every day there are five popular books from 2025–2026: read the plot and name the book. Each miss reveals a clue (genre and year, main character, author). Scores run 4/3/2/1 per book, for a perfect day of 20.

Static site, no build step: open `index.html` in a browser, or host the folder anywhere (e.g. GitHub Pages).

- `books.js`: the puzzle pool
- `app.js`: daily selection, guessing, clues, stats, sharing
- `styles.css`: mid-century styling
